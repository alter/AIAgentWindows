## Constants (G-4g, sRGB, 2.4 exponent)

- Exponents: `mainTRC` 2.4, `normBG` 0.56, `normTXT` 0.57, `revTXT` 0.62, `revBG` 0.65 — https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/README.md#L228 and https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/src/apca-w3.js#L146-L162
- sRGB coefficients: `sRco` 0.2126729, `sGco` 0.7151522, `sBco` 0.0721750 — https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/README.md#L230 and https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/src/apca-w3.js#L153-L156
- Clamps: `blkThrs` 0.022, `blkClmp` 1.414, `loClip` 0.1, `deltaYmin` 0.0005; scalers: `scaleBoW` 1.14, `scaleWoB` 1.14, `loBoWoffset` 0.027, `loWoBoffset` 0.027 — https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/README.md#L232-L235 and https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/src/apca-w3.js#L164-L172
- Luminance `Y` is not the WCAG one: each 8-bit channel `c` becomes `(c/255)^2.4` (a pure power, no linear toe), then `Y = sRco*R + sGco*G + sBco*B` — https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/src/apca-w3.js#L623-L650
- `APCAcontrast(txtY, bgY)` returns `0` when either Y is NaN, below 0 or above 1.1; soft-clamps each Y below `blkThrs` with `Y + (blkThrs - Y)^blkClmp`; returns `0` when `|bgY - txtY| < deltaYmin` — https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/src/apca-w3.js#L191-L231
- Dark text on a lighter background (bgY > txtY, "BoW"): `S = (bgY^normBG - txtY^normTXT) * scaleBoW`; `Lc = 0` when `S < loClip`, else `(S - loBoWoffset) * 100`. Light text on a darker background ("WoB"): `S = (bgY^revBG - txtY^revTXT) * scaleWoB`; `Lc = 0` when `S > -loClip`, else `(S + loWoBoffset) * 100`. The result is signed: positive for dark on light, negative for light on dark; never take an absolute value before the level comparison is chosen by polarity — https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/src/apca-w3.js#L233-L263
- Range: "signed float -108.0 to 106.0 (approx)"; "APCA is polarity sensitive!", text first, background second — https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/README.md#L123 and https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/src/apca-w3.js#L106-L115
- Alpha is blended per channel in sRGB before the Lc is computed: `out = bg * (1 - alpha) + fg * alpha`, rounded. The project forbids translucent tokens, so the gate has no blending — https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/src/apca-w3.js#L729-L740

## Levels by use (Bronze, Simple Mode)

- Bronze "covers primary content text only"; "There is no font lookup table, only a set of general conformance levels"; "There is no specified minimum font size"; spot text (disabled, placeholder, ancillary, decorative), logos and incidental text in images are not covered. The page is a draft ("beta"), undated, last change-log entry 2023-02-10 — https://readtech.org/ARC/#bronze and https://readtech.org/ARC/tests/bronze-simple-mode/
- Body text: minimum Lc 75, preferred Lc 90. "Body text" is a block or column of more than two continuous lines of content text — https://readtech.org/ARC/tests/bronze-simple-mode/
- Other content text (primary content that is not body text, up to two and a half lines; it names tool-tips, spoilers, navigation and form fields): minimum Lc 60 — https://readtech.org/ARC/tests/bronze-simple-mode/
- Large fluent content (fonts larger than 36px): minimum Lc 45, maximum Lc 90 — https://readtech.org/ARC/tests/bronze-simple-mode/
- Bronze names no level for non-text (icons, arrows, control borders, focus ring): the repository index says "Non Text Contrast: PLACEHOLDER for the non-text guidelines (coming soon!)" — https://git.apcacontrast.com/
- Floors from the library: sub-fluent text may be lowered by Lc 15 "but in no case less than Lc 30"; spot text (copyright, disabled, placeholder) by Lc 25 "but in no case less than Lc 30"; fonts larger than 24px with weight 300 or more have a maximum of Lc 90 — https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/README.md#L197-L206
- Font lookup table (Barlow reference font, px by weight 100-900 per Lc row, step 5): the code marks `999` as prohibited, `777` as non-text at that stroke; rows Lc 0-10 are all `999`, rows Lc 15-20 are `777` at every weight, so the table puts the start of non-text use at Lc 15; "Lc values under 70 should have Lc 15 ADDED if used for body text" — https://github.com/Myndex/apca-w3/blob/6c5c066cf0c853507930a4239b129283b8e05353/src/apca-w3.js#L458-L510
- Project decision, since no published Bronze level exists for non-text: icons, disclosure arrows, control borders and the focus ring use Lc 45 (the Bronze minimum for the largest, least demanding text, and above every published floor: Lc 30 for spot text, Lc 15 for the table's non-text), together with the WCAG 3:1 of 1.4.11. Body text of the feed and inputs uses Lc 75, other text Lc 60, headings Lc 45 only when larger than 36px, otherwise Lc 60 — recorded under Assumptions of `tasks/10-app-shell/05-design-contrast/PLAN.md`; source of the three text levels: https://readtech.org/ARC/tests/bronze-simple-mode/
