TASK: per-run room context, rooms per project

GOAL
  A room run takes its rooms folder, project and working folders from a
  per-run context instead of the one folder fixed at app start, so rooms
  live under their project (`<userData>/projects/<id>/rooms/`), a project
  room runs its CLI participants in the project folder without writing into
  it, a room of a missing project does not start and nothing is recreated,
  and "No project" rooms behave as before (docs/plans/projects.md D19, D26,
  T11). Serves milestone M3.
