TASK: agents inside a project, Codex claim in a shared folder

GOAL
  An agent added inside a project carries its `projectId` and works in the
  project: a CLI agent runs in the project's realpath with no folder picker (a
  missing or moved folder refuses the start with a readable reason), a site
  agent keeps the kind's partition, an OpenRouter chat is stored under the
  project's storage folder. The project node lists its agents with a "+" and
  closing a project closes them. Codex claims skip a room `codex exec` rollout
  and stay unique per agent. Projects are usable after this task
  (docs/plans/projects.md D1, D3, D9, D20, D27, AC2 agent and claim parts, T09).
  Serves milestone M3.
