TASK: turn profile, deny list, CLI isolation in a project room

GOAL
  A CLI turn of a project room runs inside the owner's real repository, so it
  runs with a turn profile that applies no user, project or local settings,
  denies the project's secrets to `Read`, names no web tool, adds no
  `<shared>` directory and never asks the CLI to skip its safeguards; a room
  outside any project keeps today's argv. The turn writes nothing into the
  project folder (docs/plans/projects.md D5, D8, D22, D23 TurnProfile part,
  AC4 CLI, env and snapshot parts, T12). Serves milestone M3.
