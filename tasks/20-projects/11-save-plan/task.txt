TASK: Save plan into the project

GOAL
  A button on the final result of a project room saves its raw final text to
  <project>/docs/plans/<slug>.md: main reads the text from the room record,
  rewrites every status: running line of the first 8 lines to status: draft,
  creates docs/ and docs/plans/ one level at a time after lstat, refuses a
  symlinked component or target and a parent outside the project's realpath,
  asks before replacing an existing file and moves it to the Trash first, and
  writes through the file store with an exclusive temp file
  (docs/plans/projects.md D6, AC7, T14). Serves milestone M3: project rooms
  usable with CLI participants.
