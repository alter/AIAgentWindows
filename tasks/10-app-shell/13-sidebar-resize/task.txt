TASK: sidebar resize — a draggable divider between the sidebar and the work area, width kept across restarts

GOAL
  The divider between the left panel and the work area moves: by mouse drag
  and by keyboard; site views follow it; the width survives an app restart.
  Owner's request of 2026-10-23 ("разделитель между левой панелью ... статический,
  а хотелось бы его двигать уметь"). Serves no gate.

CONTEXT
  src/shared/site-layout.ts (SIDEBAR_WIDTH constant, siteBounds used by the main process for site views)
  src/main/site-views.ts (WebContentsView bounds)
  src/renderer/index.ts:12 (--sidebar-width set from the constant)
  src/renderer/styles.css (.sidebar flex basis var(--sidebar-width))
  src/shared/agents.ts (AppState in agents.json), src/main/agent-controller.ts (persist)
  docs/tech/electron@44.6.0.md

SCOPE
  + S1 a vertical separator between sidebar and content (role="separator", aria-orientation vertical, aria-valuenow/min/max in px, focusable); pointer drag resizes live; ArrowLeft/ArrowRight by 16 px, Home/End to min/max; double-click resets to the default 260
  + S2 width limits: min 180 px, max 50 % of the window width (and never above 600 px); a window resize clamps a stored width
  + S3 site views (ChatGPT, Grok, DeepSeek) are laid out from the current width: siteBounds takes the width as a parameter; the renderer reports the width to the main process through a validated IPC `layout:sidebar` (integer px in range), throttled during a drag
  + S4 the width is stored in agents.json (`sidebarWidth`, optional; old files load) and applied before the first paint
  − colours of the divider beyond existing tokens (--border, --focus) — 10-app-shell/12-sidebar-palette
  − collapsing the sidebar completely — not requested
  indivisible: one width flows renderer → IPC → main layout and the state file; one smoke covers it
