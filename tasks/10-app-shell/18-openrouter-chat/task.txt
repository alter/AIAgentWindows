TASK: openrouter chat — a sidebar agent that chats with one OpenRouter model

GOAL
  "OpenRouter" in the sidebar "+" menu creates a chat agent: a pane with the
  conversation, a model picker (Free / Paid filter), effort and web search
  controls, streaming replies with Stop, and the conversation kept across
  restarts. Owner's answer of 2026-10-23 ("Room + отдельный чат").

CONTEXT
  docs/tech/openrouter@2026-10-23.md (S4 streaming, reasoning, S5 web search, errors, Implications: chat pane)
  src/shared/agents.ts (AgentKind, Agent), src/main/agent-controller.ts
  src/renderer/content.ts (panes per agent kind), src/renderer/sidebar.ts ("+" menu)
  src/renderer/room-feed.ts (entries drawn with textContent, Copy)
  tasks/10-app-shell/16-openrouter-account/PLAN.md

SCOPE
  + S1 agent kind `openrouter` with its model, effort and web settings; label "OpenRouter · <model name>" until renamed; old state files load
  + S2 chat pane: messages (user and model) drawn with textContent, an input with Enter to send and Shift+Enter for a new line, Stop while streaming, Copy on each reply, model picker with the Free / Paid / All filter, effort and Web controls as in the room row
  + S3 streaming in the main process (SSE: comments skipped, deltas accumulated, [DONE], usage from the last chunk, mid-stream error shown as a failed reply); deltas reach the renderer through an event channel; Stop aborts the request
  + S4 the conversation is stored per agent in <shared>/openrouter/<agentId>.json (atomic writes, unreadable files refused and never rewritten) and sent as messages on every request; closing the agent keeps the file
  + S5 errors as a failed reply with readable text (401, 402, 429, length with empty content)
  − Room participants — 10-app-shell/17-openrouter-room
  − images and files in the chat — not requested
  − markdown rendering — replies are plain text, as in the Room feed
  indivisible: the pane, the stream channel and the conversation store change together for one agent kind
