TASK: agent identity — rename agents in the sidebar and show the products' own icons

GOAL
  Agents in the sidebar can be renamed like rooms, and every agent kind shows
  its product's logo (Claude Code, Codex, ChatGPT, Grok, DeepSeek; OpenRouter
  once it exists) instead of a generic glyph. Owner's request of 2026-10-23
  ("не умеем переименовывать агентов, и иконок нет от агентов правильных, надо
  бы брать их официальные иконки"). Serves no gate.

CONTEXT
  src/renderer/sidebar.ts (agent items, kindIcon, context menu), src/renderer/icons.ts
  src/renderer/room-tree.ts (rename in place: context menu / F2, Enter saves, Escape cancels)
  src/shared/agents.ts (Agent.title), src/main/agent-controller.ts
  https://github.com/lobehub/lobe-icons (MIT; the source of the vendored SVGs, pinned version written up by T01 in docs/tech/ before any design)
  https://openai.com/brand , https://x.ai/legal/brand-guidelines , https://openrouter.ai/brand (use as provided, no recolour, no endorsement)

SCOPE
  + S1 rename: context menu "Rename" and F2 on an agent item edit its title in place (Enter saves, Escape cancels, 1..80 chars, no control characters); validated IPC `agent:rename`; stored in agents.json; the pane header and close-button names follow
  + S2 icons: SVG files vendored from @lobehub/icons-static-svg at one pinned version into src/renderer/assets/icons/ with a LICENSE note and the source URL of each file; colour variants where the brand has one, mono marks (OpenAI, Grok) drawn in var(--text) as the brands' own black/white marks; no other recolouring, no stretching
  + S3 the icon tile: the logo on a neutral tile from palette tokens (non-text pair Lc 45 / 3:1 for mono marks in both palettes); accessible name stays the agent title
  + S4 SVG is loaded as an <img> from a bundled file or as a sanitized static string built at build time — never parsed from a runtime string with innerHTML
  + S5 the "+" buttons of "# Rooms" and "Agents" have one size and one right edge in the sidebar (owner, 2026-10-23: "этот + не может выровнять ... зачем он туда-сюда плавает?")
  − OpenRouter's own icon wiring — 10-app-shell OpenRouter tasks (the file is vendored here)
  − renaming Room participants — their labels come from kind, model and effort
  indivisible: the agent item is rewritten once for both the rename editor and the new icon
