TASK: room layout — saved rooms as a tree under # Rooms in the sidebar, rename, participants as a table

GOAL
  Saved rooms are listed in the sidebar under "# Rooms" like Slack channels and
  open with one click; a room is named from its first prompt and can be
  renamed; participants are a table, one row per participant, in relay order,
  with a button to add a row. Owner's request of 2026-10-23 (docs/PROJECT.md §3,
  Room row). Serves no gate.

CONTEXT
  tasks/10-app-shell/04-room-archive/PLAN.md (record, list, reopen)
  tasks/10-app-shell/03-room-participants/PLAN.md (rows, ids, finalizer)
  src/renderer/sidebar.ts (Room item, agent list)
  src/renderer/room-pane.ts (rooms select, participant rows, finalizer select)
  src/shared/room-model.ts (RoomRecord, parseRoomRecord, relaySchedule follows the participants order)
  src/shared/room-view.ts
  src/main/room-service.ts (atomic record write after every entry)

SCOPE
  + S1 room title: a record carries an optional title (1..80 characters, no control characters); without one the title is derived from the first prompt; old records parse unchanged
  + S2 rename through room-service (`room:rename`, validated id and title), so a rename during a run is carried by the next record write and never lost to it; an unreadable record is refused and never rewritten
  + S3 sidebar tree: "# Rooms" header with a collapse arrow and "+" (new room); below it every saved room by title, newest first, the opened one marked selected; click opens; context menu "Rename" edits the title in place (Enter saves, Escape cancels); the list refreshes on start, rename, open and app start; the select in the Room pane is removed
  + S4 participants table: columns #, Agent, Model, Effort, Final (radio), actions (move up, move down, remove); one "Add participant" menu with Claude Code, Codex, ChatGPT, Grok, DeepSeek; a site already in the table or without an adapter is disabled in the menu; row order is relay order; removing the final writer's row falls back by the existing default rule
  + S5 keyboard and screen reader: table headers with scope, action buttons named with the instance label, move up disabled on the first row and move down on the last, focus kept on the moved row's button or a neighbour after move and remove, tree header with aria-expanded, the opened room with aria-current
  − colours, palettes, arrows of spoilers — 10-app-shell/05-design-contrast
  − deleting a saved room — not requested; absent in the ledger
  − drag-and-drop reordering — buttons only, keyboard operable
  indivisible: the room list moves from the pane to the sidebar and the rows move to the table in the same pane; both rewrite the same smoke specs
