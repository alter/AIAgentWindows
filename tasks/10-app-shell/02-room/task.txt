TASK: room — broadcast and relay rounds

GOAL
  A "Room" above all agents: one prompt to every chosen participant, or a relay
  A→B→C→…→A for N rounds in which each participant receives the whole room
  history; CLI and web agents take part; the final result can be carried into
  a working session. Owner's request and decisions of 2026-10-21 (docs/PROJECT.md §3).

SCOPE
  + S1 Room model: participants, mode (broadcast | relay), rounds 1..50, relay schedule that returns to the first participant, history entries with author and time
  + S2 history as markdown in <shared>/rooms/<room-id>.md, written after every reply
  + S3 room-owned CLI sessions in read-only modes: claude --permission-mode plan, codex --sandbox read-only; prompts are submitted by the app without confirmation
  + S4 CLI turn driver: send, detect the end of the turn from the transcript, read the reply
  + S5 web adapters for ChatGPT, Grok, DeepSeek: insert, submit, wait for the end of generation, read the last reply; one isolated adapter per site, run from the main process in an isolated world
  + S6 Room UI: sidebar item at the top, feed with author labels, prompt box, participant checkboxes, mode, rounds, Start/Stop, progress
  + S7 "Carry result": the final reply or the whole history pasted (not submitted) into a chosen working session
  − the owner's working sessions never receive auto-submitted text — S7 pastes only
  − OpenAI API participants — the OpenAI API provider task
  − import of existing local sessions — its own task
  indivisible: the orchestrator, the drivers and the UI share one room state; workers run it as sequential plan tasks
